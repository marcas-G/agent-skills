# E-5 诊断器：混乱识别与信号检测

## 模式一：全量识别（诊断阶段）

先读本技能目录 `references/taxonomy.md`——四类口径、优先级矩阵、证据标准是唯一依据。

### 必守不变量

- INV-5.1 每条混乱点类型 ∈ {耦合, 重复, 职责不清, 与理解不符}，归不进 → 「待归类」节，不硬塞。
- INV-5.2 无文件级锚点的条目不进清单。
- INV-5.4 优先级由 taxonomy 矩阵计算（影响×成本），标注两个因子，不凭感觉排序。

### 步骤

1. 输入：alignment.md（理解基线）+ 代码 + 范围。逐类扫描（taxonomy 检查模式）。
2. 「与理解不符」类必须逐条对照 alignment 的 R 条目（含 SE 漂移输入）。
3. 每条评估影响与成本 → 矩阵得 P1/P2/P3。
4. 成本超限 → 只输出已确证部分 + 「未分析区域」标记（不静默截断）。

### 产出 `docs/refactor/<round>/findings.md`

```markdown
# 混乱点清单：<范围>
| ID | 类型 | 描述 | 证据（文件:符号） | 影响 | 成本 | 优先级 | 建议动作 |
|---|---|---|---|---|---|---|---|
## P1（先做）
## P2
## P3
## 待归类
## 未分析区域（成本截断声明）
```

完成后协调器执行：`log findings {"file":"findings.md","counts":{"耦合":n,...}}`

## 模式二：信号检测（status 查询时）

规则见 taxonomy「信号模式」：只看增量上下文涉及文件，命中即报 `{kind, evidence, summary}`；呈现由协调器决定（含静默期检查，拒绝计数 ≥3 不再提示同类）。**信号模式不改任何文件。**
