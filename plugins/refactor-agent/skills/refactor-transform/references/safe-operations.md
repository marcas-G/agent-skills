# 安全类重构清单（DRV-3 / INV-7.5——显式枚举，降级模式的硬边界）

> 降级模式（无测试）下改造动作必须 ∈ 本清单；不在清单内 = 需决策④例外审批或跳过。normal 模式下本清单仍是默认动作集，清单外操作按风险分级处理。

## 允许（不改行为语义、不改测试断言）

1. **重命名**：变量/函数/类/文件的更名（引用同步更新）。
2. **移动**：文件/代码块位置调整（导入路径同步）。
3. **提取**：从长函数提取子函数/子模块；提取常量/类型/配置。
4. **内联**：单用途的间接层收敛（内联变量/单行包装函数）。
5. **导入整理**：排序、去重、删除未用导入。
6. **类型/标注增强**：加类型标注、docstring、注释——不改变执行路径。
7. **纯结构提取**：重复段收敛为共享函数/模块（**逐份比对行为等价后才允许**，比对依据写进批次说明）。

## 不在清单（一律走例外审批/跳过）

- **删除代码**（死代码/冗余分支/废弃导出）——中风险，normal 模式走决策④，degraded 模式默认跳过（除非用户逐条批准）。
- **接口/签名变更**（参数增删改、返回语义变化）——高风险。
- **测试断言修改**——高风险，须决策④。
- **控制流重写**（条件合并/循环变换/异常路径调整）——高风险。

## 自检规则（每批提交前）

diff 审查四问：① 改动文件 ⊆ 批次计划文件？② 是否出现清单外操作？③ 测试文件是否被改动（degraded 模式下禁止）？④ 有无夹带（与批次目标无关的行）？——任一不符 → 撤销本批工作区改动，不提交。
