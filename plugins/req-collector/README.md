# req-collector

需求收集访谈插件（Claude Code plugin）：把散乱、模糊、多轮的需求输入收敛为要素齐全、可直接进开发的结构化需求文档。

## 安装

从 marketplace 安装 `req-collector`（或本仓库作为插件源添加）。

## 使用

```
/req-collector:req [需求描述]     # 留空则自动检测并继续上次未完成的收集
```

- 触发后自动路由：全新收集 / 断点续收 / 补充更新已有需求
- 每轮你只需：粘贴聊天记录、转述、或回答追问（单轮追问 ≤3 个）
- 五要素（问题/场景/干系人/边界/验收标准）齐备或显式挂起未决后，生成确认文档

## 产物

- `docs/requirements/<日期>-<slug>/state.md` —— 中间状态（断点续收的依据，可手工编辑）
- `docs/requirements/<日期>-<slug>/requirement.md` —— 定稿需求文档

目录可通过项目 CLAUDE.md 中定义 `REQ_COLLECT_DIR` 修改。

## 特性

- 断点续收：每轮落盘，会话中断/上下文耗尽后重进 `/req` 即从断点继续
- 诚实性：给不出的要素标 `[UNRESOLVED]`，矛盾并列 `[CONFLICT]` 请你裁决，绝不编造
- 多需求切分：一段输入混着多个需求时自动拆分
- 零外部依赖：纯指令资产，无服务、无 API key、无网络调用
